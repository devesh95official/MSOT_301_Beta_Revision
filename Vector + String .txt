============================================================
1. VECTOR
============================================================

vector is a dynamic array.

Normal array:

int a[5];

Size is fixed.

Vector:

vector<int> v;

Size can grow or shrink.


------------------------------------------------------------
2. INCLUDING VECTOR
------------------------------------------------------------

#include <bits/stdc++.h>
using namespace std;


------------------------------------------------------------
3. CREATING A VECTOR
------------------------------------------------------------

vector<int> v;

Empty vector.


vector<int> v(5);

Vector of size 5.

Initial values:

0 0 0 0 0


vector<int> v(5, 10);

Vector of size 5.

Initial values:

10 10 10 10 10


vector<int> v = {10, 20, 30, 40};

------------------------------------------------------------
4. ACCESSING ELEMENTS
------------------------------------------------------------

vector<int> v = {10, 20, 30, 40};

v[0]       -> 10
v[1]       -> 20
v[2]       -> 30
v[3]       -> 40


Index always starts from 0.


v[0] = 100;

Now:

100 20 30 40


------------------------------------------------------------
5. SIZE
------------------------------------------------------------

v.size()   // O(1)

Returns number of elements.


Example:

vector<int> v = {10, 20, 30};

cout << v.size();

Output:

3


Important:

v.size() is NOT the last index.

For size = 3:

indexes are:

0 1 2


------------------------------------------------------------
6. ADDING ELEMENTS
------------------------------------------------------------

push_back()   // O(1) but if u insert begin then O(n)

Adds an element at the end.


vector<int> v;

v.push_back(10);
v.push_back(20);
v.push_back(30);


Vector:

10 20 30


------------------------------------------------------------
7. REMOVING LAST ELEMENT
------------------------------------------------------------

pop_back()   // O(1)  but if b/w or start then O(n)


vector<int> v = {10, 20, 30};

v.pop_back();


Now:

10 20


pop_back() removes only the LAST element.

------------------------------------------------------------
20. MINIMUM AND MAXIMUM
------------------------------------------------------------

*min_element(v.begin(), v.end()) // O(n)

*max_element(v.begin(), v.end()) // O(n)


Example:

vector<int> v = {5, 2, 8, 1};

cout << *min_element(v.begin(), v.end());

Output:

1


cout << *max_element(v.begin(), v.end());

Output:

8


WHY * ?

min_element() returns an iterator.

* is used to get the actual value.

VECTOR ITERATORS
============================================================

begin()

Points to first element.


end()

Points just AFTER the last element.


Example:

vector<int> v = {10, 20, 30};

v.begin() -> 10
v.end()   -> after 30


This is why we write:

sort(v.begin(), v.end());

============================================================
FREQUENCY OF CHARACTERS
============================================================

For lowercase English letters:

int freq[26] = {0};

for (char c : s)
{
    freq[c - 'a']++;
}


Example:

s = "banana"


freq['a' - 'a'] -> 3
freq['b' - 'a'] -> 1
freq['n' - 'a'] -> 2


------------------------------------------------------------
Using vector
------------------------------------------------------------

vector<int> freq(26, 0);

for (char c : s)
{
    freq[c - 'a']++;
}


============================================================
PALINDROME
============================================================

A palindrome reads the same from both sides.

Examples:

madam
level
racecar


Simple method:

string t = s;

reverse(t.begin(), t.end());

if (s == t)
{
    cout << "Palindrome";
}
